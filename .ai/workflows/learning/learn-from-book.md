# Learning Workflow — Learn From Book

- **Prompt:** `.ai/prompts/roles/source-learning-agent.md`
- **Template:** `templates/source-book.template.md`

## Inputs

- A book + chapter(s)
- The decision or skill you want it to inform

## Steps

1. State why this chapter, now.
2. Extract core ideas and reusable mental models (confirmed).
3. Separate your interpretation.
4. Apply one idea to a real project decision as the exercise.
5. Write the Arabic summary.

## Artifacts Produced

- `docs/learning/source-summaries/<slug>.md`
- Entry in `learning-sources/source-index.md`

## Exit Criteria

- One mental model captured and tied to a concrete decision.
