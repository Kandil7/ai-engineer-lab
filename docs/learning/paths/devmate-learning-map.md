## Required Skills

Concepts DevMate needs to reach its A2-A6 milestones, in prerequisite order:

- `python.production` — Production Python — bounded-memory ingest, typed errors.
- `python.testing` — Test strategy — unit to regression gates.
- `backend.fastapi-service` — FastAPI service — `/health`, `/ask`, `/ingest`.
- `databases.sql-schema` — SQL schema and indexes — conversations, messages, cost.
- `databases.redis` — Redis cache and queues — semantic cache, job queue.
- `deploy.docker` — Docker and deployment — multi-stage image, public URL.
- `llm.fundamentals` — LLM fundamentals — tokens, temperature, context.
- `llm.streaming` — Streaming and structured outputs — SSE ask, validated JSON.
- `llm.prompt-engineering` — Prompt engineering — versioned templates.
- `obs.tracing` — Observability and tracing — every call a span.
- `obs.cost-tracking` — Cost tracking — dollars per request.
- `rag.embeddings` — Embeddings — model selection, batch, cache.
- `rag.chunking` — Chunking — fixed, recursive, AST-aware.
- `rag.vector-store` — Vector store (Qdrant) — ingest and query.
- `rag.hybrid-retrieval` — Hybrid retrieval — dense plus BM25 fusion.
- `rag.reranking` — Reranking — metric delta vs no rerank.
- `rag.citations-abstention` — Citations and abstention — grounded answers.
- `eval.golden-datasets` — Golden datasets — expected sources per question.
- `eval.retrieval-metrics` — Retrieval metrics — recall@k, MRR.
- `eval.faithfulness` — Faithfulness — grounding and citation precision.
- `eval.llm-as-judge` — LLM-as-judge — calibrated rubric.
- `eval.eval-in-ci` — Evaluation in CI — metric regression gate.
- `agents.tool-use` — Tool use — one hand-rolled tool loop.
- `agents.react` — ReAct — step cap and loop detection.
- `agents.mcp` — MCP — server reachable from a real client.
- `prod.semantic-cache` — Semantic caching — hit-rate metric.
- `prod.guardrails` — Guardrails — injection defence, size limits.
- `system-design.contracts` — Component contracts — compatibility, migration.
- `system-design.failure-modes` — Failure modes — degradation, runbooks.
