## How to Use the Quizzes

### Self-Assessment
1. Start with the topic you're least familiar with
2. Answer all questions before checking the answer key
3. Use the difficulty ratings to prioritize your study
4. Review explanations for questions you got wrong

### Study Workflow
1. **Read the Topic Overview** at the top of each quiz
2. **Answer Questions** without looking at answers first
3. **Check Your Score** using the score tracking table
4. **Review Explanations** for all questions, especially wrong answers
5. **Revisit Weak Areas** by re-reading relevant lecture materials

### Team Learning
- Use quizzes as pre-reading assessments before lectures
- Create study groups to discuss difficult concepts
- Quiz each other using the question bank
- Track team progress through the quiz series
