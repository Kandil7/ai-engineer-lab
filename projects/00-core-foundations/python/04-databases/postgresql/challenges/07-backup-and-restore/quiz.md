# Challenge 07 — Quiz: Backup and Restore

1. An unverified backup is:
   - A) fine  (B) not a backup  (C) compressed  (D) offsite
2. RPO measures:
   - A) restore speed  (B) tolerable data loss  (C) disk size  (D) cost
3. Point-in-time recovery replays:
   - A) full dumps  (B) WAL segments to a target time  (C) indexes  (D) logs
4. Content drift at identical row counts is caught by:
   - A) exit status  (B) byte-for-byte comparison  (C) row counts  (D) checksums of schema
5. A vector index in the backup surface is:
   - A) primary  (B) derived — rebuild instead  (C) compressed  (D) encrypted
6. The 3-2-1 rule means:
   - A) 3 scripts  (B) 3 copies, 2 media, 1 offsite  (C) 3 days  (D) 3 versions
7. WAL redelivery means redo records must be applied:
   - A) twice  (B) at most once each  (C) never  (D) randomly
8. The restore runbook is written from:
   - A) imagination  (B) the drill's measured steps  (C) the docs  (D) the vendor

**Answers:** 1-B, 2-B, 3-B, 4-B, 5-B, 6-B, 7-B, 8-B
