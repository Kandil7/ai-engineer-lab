# Challenge 36 — Quiz: Separation of Concerns

1. A module with two unrelated reasons to change is called:
   - A) cohesive  (B) a god object  (C) pure  (D) idempotent
2. `typing.Protocol` describes an interface:
   - A) by inheritance  (B) structurally (methods match)  (C) by ABC only  (D) by decorators
3. Dependency injection means a component receives collaborators:
   - A) from globals  (B) via its constructor  (C) by importing them  (D) never
4. The composition root is where:
   - A) business rules live  (B) concrete classes are named and wired  (C) logging is configured  (D) tests run
5. A frozen dataclass prevents:
   - A) instantiation  (B) attribute mutation  (C) inheritance  (D) serialization
6. The engine-swap test proves that:
   - A) the engine is fast  (B) validation is independent of the engine  (C) the index is durable  (D) queries match
7. Library code should configure logging handlers:
   - A) always  (B) never — the application does  (C) on import  (D) in tests only
8. A spy test double is used to:
   - A) return canned data  (B) record calls for assertions  (C) slow tests down  (D) mock time

**Answers:** 1-B, 2-B, 3-B, 4-B, 5-B, 6-B, 7-B, 8-B
