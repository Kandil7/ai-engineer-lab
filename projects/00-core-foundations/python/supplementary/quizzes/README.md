# Python Foundations Quizzes

## Overview

This directory contains comprehensive multiple-choice quizzes covering essential Python libraries and frameworks for AI engineering. Each quiz is designed to test your knowledge and reinforce learning through practical questions with detailed explanations.

## Quiz Topics

### FastAPI
- [FastAPI Basics](./fastapi-basics-quiz.md) - Core concepts: routes, Pydantic models, request/response, dependency injection
- [FastAPI Advanced](./fastapi-advanced-quiz.md) - Middleware, authentication, WebSockets, testing, production patterns

### NumPy
- [NumPy Basics](./numpy-basics-quiz.md) - Array creation, indexing, operations, broadcasting, core concepts
- [NumPy Advanced](./numpy-advanced-quiz.md) - Linear algebra, FFT, random distributions, memory management, performance

### Pandas
- [Pandas Basics](./pandas-basics-quiz.md) - DataFrames, Series, data selection, filtering, basic operations
- [Pandas Advanced](./pandas-advanced-quiz.md) - MultiIndex, time series, groupby, performance optimization, advanced operations

### Visualization
- [Matplotlib Quiz](./matplotlib-plotting-quiz.md) - Line plots, scatter plots, histograms, customization, object-oriented API

### Scientific Computing
- [SciPy Quiz](./scipy-quiz.md) - Optimization, integration, linear algebra, statistics, signal processing

### Web Frameworks
- [Django Quiz](./django-quiz.md) - Models, views, templates, ORM, admin, REST framework

### Databases
- [SQLAlchemy Basics](./sqlalchemy-basics-quiz.md) - Core vs ORM, declarative models, session lifecycle, relationships, 2.0 querying
- [SQLAlchemy Advanced](./sqlalchemy-advanced-quiz.md) - N+1 and eager loading, async SQLAlchemy, advanced patterns, DB testing, repository pattern

## How to Use

### Study Approach
1. **Start with basics** - Complete the basics quiz for each topic before moving to advanced
2. **Time yourself** - Each quiz has a suggested time limit to simulate real conditions
3. **Review explanations** - Read all explanations even for correct answers to deepen understanding
4. **Track progress** - Use the score tracking to monitor improvement

### Quiz Format
Each quiz contains:
- **15-20 multiple-choice questions** with 4 options (A/B/C/D)
- **Difficulty levels** - Easy, Medium, and Hard questions
- **Correct answers** with detailed explanations
- **Answer key** for quick reference
- **Score tracking** with proficiency levels

### Scoring Guide

| Score Range | Proficiency Level | Recommended Action |
|-------------|-------------------|-------------------|
| 90-100% | Expert | Move to next topic or advanced quiz |
| 70-89% | Proficient | Solid foundation, review missed topics |
| 50-69% | Developing | Practice more, revisit documentation |
| Below 50% | Beginner | Study the topic thoroughly before retaking |
