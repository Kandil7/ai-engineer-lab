# Challenge 05 — Quiz: Architecture Decision Records

1. An ADR records:
   - A) every commit  (B) one significant decision  (C) a bug report  (D) a meeting note
2. The highest-value ADR section is:
   - A) title  (B) alternatives considered (with rejection reasons)  (C) links  (D) status
3. Once accepted, an ADR's content may be:
   - A) edited  (B) immutable — supersede with a new ADR  (C) deleted  (D) renamed
4. The status lifecycle is:
   - A) draft, final  (B) proposed, accepted, deprecated, superseded  (C) open, closed  (D) new, old
5. An ADR's decision should be phrased as:
   - A) "we might"  (B) "we will ..."  (C) "someone said"  (D) "TBD"
6. An ADR without an enforcement link is:
   - A) fine  (B) a wish  (C) a bug  (D) a design doc
7. When is an ADR warranted?
   - A) for every library  (B) hard-to-reverse + real alternatives + future "why?"  (C) never  (D) only on Fridays
8. The effective decision for a topic is the one that is:
   - A) longest  (B) highest-numbered and accepted  (C) first in the file  (D) newest by filename

**Answers:** 1-B, 2-B, 3-B, 4-B, 5-B, 6-B, 7-B, 8-B
