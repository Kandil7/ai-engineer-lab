## Questions

### Question 1 — Easy

**What is the shell?**

- A) A file
- B) The program that runs commands
- C) A directory
- D) A cache

<details>
<summary>Reveal Answer</summary>

**Correct Answer: B**

**Explanation**: The prompt is where you type; the shell interprets and runs.

</details>
